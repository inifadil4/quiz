# Perpustakaan Mini (PHP OOP + MySQL)

1. Jalankan Apache dan MySQL di XAMPP Control Panel.
2. Salin folder `perpustakaan` ke `C:\xampp\htdocs\`.
3. Buka http://localhost/phpmyadmin, klik tab Import, pilih `database.sql`, lalu klik Go.
4. Buka http://localhost/perpustakaan/

Jika password MySQL kamu bukan kosong, ubah konstanta di `classes/Database.php`.
